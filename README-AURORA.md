# MDS Aurora cinematic upgrade

This upgrade builds on the original MDS website. It keeps the original hero video, founder and appointment imagery, portfolio destinations, page layouts, and inquiry/booking integrations while adding a brand-blue and violet visual direction.

- `css/aurora.css` adds the palette, cinematic light layers, glass surfaces, generated-art composition, responsive refinements, and reduced-motion styles.
- `js/aurora.js` adds motion preferences, visibility-aware hero playback, light pointer parallax, reading progress, intent-based project previews, and mobile navigation state/keyboard support.
- `img/aurora/` contains the two generated illustrations, a smaller background export, and a lossless optimized export of the original MDS logo. The logo was not generated or redesigned.
- The existing growth section is presented near the homepage hero with a dimensional original-logo illustration and practical descriptions of the customer journey.
- Illustrative dashboard data is labeled as a demo. Several decorative statistics and unrelated project tags are replaced with descriptive content.
- Existing scripts receive limited changes to honor motion preferences and avoid loading all portfolio video players at once. Funnel qualification and submission behavior is unchanged.

Validation: JavaScript syntax checks, local asset/anchor checks, original project destinations, original form/calendar embeds, legal body text, approved Mariane/team imagery, desktop browser views, phone/tablet rendering, remembered motion preferences, appointment dialog, and project video routing. No inquiries or appointments were submitted.

The version is prepared on `aurora-cinematic-upgrade` for visual review. The restored original version remains on production `main`.
